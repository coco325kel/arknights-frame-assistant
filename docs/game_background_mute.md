# 后台自动静音（第二部分）

依赖音频快捷键提交，新增默认开启且持久保存的「游戏在后台时自动静音」。手动静音或自动静音任一成立即保持静音，回前台只解除自动部分；调高先写音量后恢复出声，后台自动策略继续生效。

本部分集中审查 `GameAudioController` 的 PID/创建时间状态、原始静音恢复记录、退出及断开会话恢复、音量目标与失败重试。复用客户端事件立即同步，500ms 巡检补处理会话；尚未加入 C++ 通知、100ms 复查窗口或稳定后 1s 调度。

会话接口由每次快照管理，不在持久状态中保存 COM 指针。原有静音和手动静音在自动恢复时保留；正常退出不回滚用户主动修改的音量。未连接设备的恢复记录写入 `mute-restore.ini`，进程身份相同时下次启动继续处理。

本部分使第一部分文档所述“无会话不保存意图、切换后需再次按键”扩展为保留运行时意图并通过巡检补应用。最终的设备通知优化在第三部分独立审查。

测试范围 Windows 11 x64。自动门禁与既有冒烟测试通过，实际游戏、后台/前台切换、设置关闭和退出恢复尚待对本分支专门验收，不能沿用第一部分或桌面完整版结果。
