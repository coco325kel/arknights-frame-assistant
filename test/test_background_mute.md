## 集成测试

> 涉及模块：GameClientRegistry、GameAudioController、GameAudioMute、SettingsService。

- [ ] **操作**：前后台切换、切换虚拟桌面；手动静音后回前台；后台调高音量；然后关闭自动开关。
- [ ] **预期**：后台静音、前台解除自动部分；手动静音保持；后台调高仍不出声；关闭自动功能仅恢复自动改变的状态。
- [ ] **操作**：原本在混音器静音后启用自动功能，正常退出 AFA；再对原本未静音的游戏重复。
- [ ] **预期**：退出分别保留原静音、恢复原出声；用户主动调好的音量保持。
- [ ] **操作**：游戏无会话时调音量，再产生声音；断开设备后关闭自动功能再重连；重启游戏后再调节。
- [ ] **预期**：保留待应用意图；重连后恢复原状态；新游戏不继承旧 PID 状态。
- [ ] **异常**：一部分会话失效或音量写入失败后继续调节和恢复 → **预期**：其他会话继续工作，未成功会话重试，写音量成功前不解除其静音。
