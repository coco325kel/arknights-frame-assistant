## 单元测试

### 功能点：设置与布局

- [ ] **操作**：打开「快捷操作」，检查原有六项及新增三项；切换简中、繁中、日语、韩语、英语和浅深主题。
- [ ] **预期**：原六项位置不变；静音、提高音量、降低音量在右列下方，自动静音开关在其下；无文字截断、重叠，底部按钮可用。
- [ ] **操作**：使用独立干净配置打开，再使用带 F3 静音绑定的既有配置打开。
- [ ] **预期**：新配置默认 F8、Ctrl+↑、Ctrl+↓，自动静音开启；既有绑定保留。
- [ ] **操作**：改为 F3、Ctrl+滚轮上/下，保存、重新打开设置、重启 AFA；再测试应用、取消和重置。
- [ ] **预期**：改键与开关按设置流程生效并持久保存；取消不应用未保存值，重置恢复默认。

### 功能点：音量步长与重复

- [ ] **操作**：从混合器设置 50%，单次调高/调低，然后按住对应键。
- [ ] **预期**：每次增减 10 个百分点，连续调节并显示百分比。
- [ ] **操作**：从 3% 调低、0% 调高、98% 调高，继续向边界外调节。
- [ ] **预期**：限制在 0%–100%，0% 能正确作为有效音量读取；到 0% 不设置额外静音标志。
- [ ] **操作**：在混合器手动改动现有游戏会话的音量后等待，再按音量快捷键。
- [ ] **预期**：等待期间不回写旧目标；下一次调节从选中参考会话的真实音量开始。

## 集成测试

### 流程：手动与后台自动静音

> 涉及模块：GameClientRegistry、GameAudioController、GameAudioMute、HotkeyService。

- [ ] **前置**：真实游戏有音频会话，另一个程序持续播放声音。
- [ ] **操作**：按静音键两次；切出游戏、回到前台；手动静音后重复前后台切换。
- [ ] **预期**：仅游戏静音/恢复；自动静音回前台解除，手动静音仍保留。
- [ ] **操作**：手动静音后分别调低、调高音量；后台自动静音期间调高并回到前台。
- [ ] **预期**：调低不解除或重新触发静音；调高先设置音量再解除手动静音，后台仍静音并有提示，回到前台恢复。
- [ ] **操作**：前台手动静音后在混合器解除已知会话静音；再制造一个新的未静音游戏会话。
- [ ] **预期**：前一操作解除手动意图；新会话不能错误清除手动意图。后台自动策略仍生效。
- [ ] **操作**：鼠标悬停操作游戏而其他窗口在前台，启用悬停热键并按音频快捷键。
- [ ] **预期**：音频操作生效且不激活游戏，仍遵守原有热键触发范围。

### 流程：设备切换、断开与会话重建

> 涉及模块：AudioNotificationBridge、原生 MTA 通知、GameAudioController。

- [ ] **操作**：在手动静音、后台自动静音、已设置目标音量三种状态下，轮流切换 Realtek、蓝牙耳机、显示器音频并切回。
- [ ] **预期**：所有活动输出上的游戏会话均同步，其他程序和系统总音量不受影响。
- [ ] **操作**：物理断开并重连设备，重建游戏音频会话，暂时禁用所有输出设备后重新启用。
- [ ] **预期**：无设备或无会话时保留意图；新会话继续执行，旧接口释放，不继承无关实例状态。
- [ ] **操作**：记录新会话可访问时间与首次成功静音时间，重复切换并检查通知及扫描统计。
- [ ] **预期**：正常通知路径目标小于 200ms；实测延迟写入反馈，不将巡检周期当成实测延迟。
- [ ] **操作**：游戏移到另一虚拟桌面再返回。
- [ ] **预期**：客户端仍被跟踪，后台静音保留，返回当前桌面后正确恢复。

### 流程：异常与恢复

- [ ] **异常**：首次音量操作时无游戏会话 → **预期**：累计增量，出现会话后从真实音量计算；已有目标则继续调整目标。
- [ ] **异常**：部分会话写音量失败 → **预期**：成功会话使用目标并可恢复出声，失败会话保持静音且重试，失败类型分别提示。
- [ ] **异常**：上项失败期间继续调低或切换手动静音 → **预期**：按最新操作顺序执行，不重新静音已出声会话，不被旧恢复意图覆盖。
- [ ] **异常**：失效、过期会话与健康设备并存 → **预期**：释放失效接口，单个失败不阻断其他设备，日志不会每轮刷屏。
- [ ] **异常**：游戏退出、重启或 PID 被复用 → **预期**：以创建时间校验，清除旧目标音量及手动状态，不操作无关进程。
- [ ] **异常**：源代码运行时缺少 AudioNotify.dll/校验清单，或改用 32 位解释器 → **预期**：降级 250ms 巡检且功能可用，降级日志限频。
- [ ] **异常**：通知注册或注销失败后重试 → **预期**：降级扫描；注销未完成不卸载模块、不把停止中的监听误报为正常。

### 流程：设置关闭、停止与退出

- [ ] **操作**：开启后台静音，切出游戏后关闭开关并应用；重复启用、关闭。
- [ ] **预期**：仅恢复自动改变的值，原先静音保持，后续再次启用仍工作。
- [ ] **操作**：正常退出 AFA，分别覆盖自动静音、手动静音、已调音量和设备断开状态。
- [ ] **预期**：恢复自动部分，保留手动及原先静音，不回滚音量；断开的恢复记录下次启动继续处理。
- [ ] **操作**：开发调试中调用 Init→Stop→Init，再触发新设备、新会话；音频处理中正常退出。
- [ ] **预期**：无重复订阅，轮询恢复，退出前完成可访问会话恢复。
